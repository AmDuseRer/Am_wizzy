# 小智工具箱项目要点归纳

## 一、核心业务逻辑

1. 用户基于账号密码注册登录，通过 JWT + 数据库令牌表实现身份校验、账号下线与权限管控。
2. 所有业务数据绑定用户 ID 做行级隔离，用户仅可查看、操作自身备忘录、密码、待办数据。
3. 用户密码采用 Bcrypt 不可逆加密存储，密码本敏感信息通过 AES 对称加密入库，前端仅脱敏展示。
4. 支持笔记、密码、待办的增删改查、分类管理、条件检索，高危操作自动记录操作日志便于追溯。
5. 待办任务自动根据截止时间判定逾期状态，支持任务优先级、多状态流转管理。

## 二、前端页面功能

主布局：左侧边菜单栏 + 顶栏（暗色模式切换，Dropdown 下拉菜单-设置按钮：用户信息/修改密码/退出登录） + 内容区
左栏支持二级菜单。
当前的一级菜单为：用户管理、备忘录、密码本、TodoList 待办。
当前有admin、user两个用户，仅admin有用户管理功能。

## 三、前端技术规范

1. 基于 Vue3+Vite 开发，采用 Vue Router 做路由管理，全局配置路由守卫统一鉴权拦截。
2. 使用 Pinia 做全局状态管理，LocalStorage 存储 JWT 令牌与用户基础信息，敏感明文禁止本地持久化。
3. Axios 统一封装请求与响应拦截器，统一挂载身份令牌、捕获异常并全局弹窗提示。
4. 采用 Element Plus 作为 UI 组件库，公共组件抽离复用，统一表单、弹窗、表格交互样式规范。
5. 使用 Pydantic 前端表单校验、Dayjs 时间格式化、CryptoJS 脱敏、JsPDF 文件导出，代码模块化拆分。

## 四、后端技术规范（FastAPI+MySQL5.7）

1. 基于 FastAPI 异步开发，Pydantic 做请求参数强校验，全局统一异常处理与标准化返回格式。
2. 使用 SQLAlchemy 作为 ORM 框架操作 MySQL5.7，InnoDB 引擎保证事务安全，所有数据表设计 user_id 实现数据隔离。
3. 采用 JWT 实现无状态鉴权，搭配用户令牌数据表管理令牌有效性，实现主动下线、密码修改后批量失效令牌。
4. 统一加密规范：用户密码 Bcrypt 加盐哈希存储，密码本敏感字段 AES 对称加密入库。
5. 内置 CORS 跨域配置，使用原生 Logging 记录业务、登录、高危操作日志，依托 FastAPI 自带 Swagger 生成接口文档。

## 五、工具功能涉及的技术规范

1. 用户安全工具：密码哈希加密、JWT 令牌签发解析、参数合法性校验、操作日志持久化存储规范。
2. 备忘录工具：关键词模糊检索、分页查询、PDF 文件流生成与前端下载、本地草稿临时存储规范。
3. 密码管理工具：AES 加解密、数据脱敏展示、敏感操作权限二次校验、加密文件导出备份规范。
4. 待办任务工具：时间范围计算、逾期状态自动判定、多条件筛选、批量数据更新事务处理规范。
5. 通用工具：全局时间格式化、跨域请求处理、请求异常统一捕获、静态资源反向代理访问规范。

================================================================================
一、核心业务逻辑
================================================================================

1. NL2SQL查询流程：自然语言问题 → LLM生成SQL → SQL安全校验（语法+列名+压力评估）→ 自动追加LIMIT → 执行查询 → 返回结果
2. 多数据库实例支持：同时管理多个ClickHouse/MySQL实例，查询时选择目标实例，各实例的Schema/向量索引/组件按实例名隔离
3. Schema语义检索：将表结构信息向量化存入ChromaDB，查询时用自然语言语义匹配最相关的表Schema，减少LLM输入token
4. SQL示例匹配：维护SQL示例库，查询时匹配相似示例作为LLM few-shot参考，提升生成质量
5. 查询保护：高风险查询（预估扫描行数超阈值）自动拒绝；无LIMIT的查询自动追加
6. 查询日志：每次查询自动记录完整日志（含查询结果数据）到MySQL，支持按用户查看历史

================================================================================
二、前端页面
================================================================================

1. 登录页：用户名密码登录，JWT认证
2. NL2SQL查询页：实例选择 + 自然语言输入 → 展示SQL/查询数据表格/执行日志
3. 查询日志页：日志列表 + 详情（含结果数据表格展示）
4. 用户管理页：用户CRUD，角色区分admin/user
5. 实例管理页（管理员）：数据库实例CRUD + 连接测试 + 设为默认
6. 表附加描述页（管理员）：为表和字段补充业务名称/描述，按实例和库分组展示（只显示有业务名称的表）
7. 表结构查看页（管理员）：从ChromaDB索引展示表结构，左右分栏（可拖拽），支持搜索，左栏可滚动

主布局：左侧边栏导航 + 顶栏（暗色模式切换/用户信息/修改密码） + 内容区

================================================================================
三、技术规范
================================================================================

后端（Python）：
  - FastAPI + Uvicorn，两个HTTP服务入口：前端配合服务(5000端口，需JWT认证) + 纯API服务(8000端口，无认证)
  - 另提供CLI交互式入口（Rich库终端渲染）
  - 三个入口共用NL2SQL核心逻辑，查询日志入库字段一致（Web用登录用户ID，API用user_id=0/username="api"，CLI用user_id=0/username="cli"）
  - 阿里云DashScope：qwen-max做SQL生成，text-embedding-v3做向量嵌入
  - ChromaDB本地持久化做Schema向量索引，按实例名隔离Collection
  - SQLAlchemy + PyMySQL做用户管理（独立MySQL库：users/query_log/instances三张表）
  - 抽象工厂模式封装数据库客户端：BaseDatabaseClient → ClickHouseClient / MySQLClient
  - JWT认证 + bcrypt密码哈希 + 实例密码Fernet对称加密存储
  - 配置从.env文件读取（阿里云Key/MySQL/JWT/查询保护参数等），数据库实例配置从MySQL instances表读取

前端（Vue3）：
  - Vue 3 Composition API + Vue Router + Axios，Vite构建
  - 无第三方UI框架，纯手写CSS组件
  - Axios请求拦截器自动附加JWT，401响应自动跳转登录
  - 支持暗色模式
  - Vite开发代理到后端5000端口

关键注意：
  - JSON序列化查询结果时需自定义Encoder处理date/datetime/Decimal类型
  - ChromaDB文档解析字段行时，不可strip()后再用前缀"  - "匹配（会丢失前导空格）
  - SQLAlchemy的create_all()不会给已有表添加新列，新增字段需手动ALTER TABLE
