# Demo 示例集

本目录用于存放各类技术栈的独立学习示例，每个子目录对应一种技术或框架。

## 目录

| 目录 | 说明 |
|------|------|
| [FastAPI_demo](./FastAPI_demo/) | FastAPI 三层架构极简待办 API |
| [JWT_demo](./JWT_demo/) | JWT 签发验签 + Token 白名单练习（2、3、4 题） |
| [AES_Fernet_demo](./AES_Fernet_demo/) | AES/Fernet 加解密 + 迷你密码本练习（1、2 题） |

## 约定

- 每个子目录自包含：代码、依赖（`requirements.txt` 等）、独立 README
- 在仓库根目录 `wizzy/` 下运行各 demo 的启动命令（见各子目录 README）
- 新增其他技术 demo 时，在 `demo/` 下新建同级目录即可，例如 `Vue_demo/`、`Django_demo/`
