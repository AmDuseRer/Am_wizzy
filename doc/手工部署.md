# 手工部署说明

## 一、Ubuntu 22 生产环境部署

### 1. 安装依赖

```bash
sudo apt update
sudo apt install -y python3 python3-venv python3-pip nodejs npm nginx mysql-server
```

### 2. 配置 MySQL

```bash
sudo mysql -e "CREATE DATABASE wizzy_db DEFAULT CHARACTER SET utf8mb4;"
sudo mysql -e "CREATE USER 'wizzy'@'localhost' IDENTIFIED BY '你的密码';"
sudo mysql -e "GRANT ALL ON wizzy_db.* TO 'wizzy'@'localhost';"
sudo mysql -e "FLUSH PRIVILEGES;"
sudo mysql wizzy_db < /path/to/server/scripts/init_db.sql
```

### 3. 部署后端

```bash
sudo mkdir -p /opt/wizzy
sudo cp -r server/* /opt/wizzy/
cd /opt/wizzy

python3 -m venv .venv
source .venv/bin/activate
pip install -r requirements.txt

# 创建 .env
cp .env.example .env
# 编辑 .env，设置 DATABASE_URL、JWT_SECRET、AES_KEY

# 生成 AES 密钥
python3 -c "from cryptography.fernet import Fernet; print(Fernet.generate_key().decode())"

# 初始化种子数据
python scripts/seed_data.py

# 测试启动
uvicorn main:app --host 127.0.0.1 --port 8000
```

### 4. 配置 systemd

```bash
sudo cp deploy/systemd/wizzy-api.service /etc/systemd/system/
sudo systemctl daemon-reload
sudo systemctl enable wizzy-api
sudo systemctl start wizzy-api
```

### 5. 构建前端

```bash
cd /path/to/web
npm ci
npm run build
sudo mkdir -p /var/www/wizzy
sudo cp -r dist/* /var/www/wizzy/
```

### 6. 配置 Nginx

```bash
sudo cp deploy/nginx.conf /etc/nginx/sites-available/wizzy
sudo ln -s /etc/nginx/sites-available/wizzy /etc/nginx/sites-enabled/
sudo rm -f /etc/nginx/sites-enabled/default
sudo nginx -t
sudo systemctl reload nginx
```

### 7. 验证

- 访问 http://服务器IP
- API 文档 http://服务器IP/docs
- 登录 admin / Admin@123

## 二、Windows 11 开发环境部署

### 1. 安装 MySQL 5.7+

从 [MySQL 官网](https://dev.mysql.com/downloads/installer/) 下载安装，记住 root 密码。

### 2. 初始化数据库

```powershell
cd c:\vscode\wizzy
mysql -u root -p < server\scripts\init_db.sql
```

### 3. 后端

```powershell
cd server
python -m venv .venv
.venv\Scripts\activate
pip install -r requirements.txt
copy .env.example .env
```

编辑 `.env`：

```ini
DATABASE_URL=mysql+aiomysql://root:你的密码@127.0.0.1:3306/wizzy_db
AES_KEY=运行下方命令生成的密钥
```

生成 AES 密钥：

```powershell
python -c "from cryptography.fernet import Fernet; print(Fernet.generate_key().decode())"
```

初始化数据并启动：

```powershell
python scripts\seed_data.py
uvicorn main:app --reload --port 8000
```

### 4. 前端

新开终端：

```powershell
cd c:\vscode\wizzy\web
npm install
npm run dev
```

访问 http://localhost:5173

## 三、常见问题

| 问题 | 解决方案 |
|------|----------|
| MySQL 连接失败 | 检查 DATABASE_URL 用户名密码、MySQL 服务是否启动 |
| AES 解密失败 | 确保 .env 中 AES_KEY 与 seed_data.py 运行时一致 |
| 前端 401 | 检查后端是否运行、CORS_ORIGINS 是否包含前端地址 |
| npm install 慢 | 使用 `npm config set registry https://registry.npmmirror.com` |
| bcrypt 报错 | 确保 bcrypt==4.2.1 与 passlib 兼容 |
