# 开发环境测试说明（Win11）

## 1. 环境准备

| 软件 | 版本要求 | 验证命令 |
|------|----------|----------|
| Node.js | 18+ | `node -v` |
| Python | 3.10+ | `python --version` |
| MySQL | 5.7+ | `mysql --version` |
| Git | 任意 | `git --version` |

## 2. 项目启动步骤

### 2.1 克隆/进入项目

```powershell
cd c:\vscode\wizzy
```

### 2.2 数据库

```powershell
# 登录 MySQL 创建库（如 init_db.sql 未自动创建）
mysql -u root -p -e "CREATE DATABASE IF NOT EXISTS wizzy_db DEFAULT CHARACTER SET utf8mb4;"
mysql -u root -p wizzy_db < server\scripts\init_db.sql
```

### 2.3 后端

```powershell
cd server
python -m venv .venv
.venv\Scripts\activate
pip install -r requirements.txt
copy .env.example .env
```

编辑 `.env` 文件：

```ini
DATABASE_URL=mysql+aiomysql://root:你的MySQL密码@127.0.0.1:3306/wizzy_db
JWT_SECRET=dev-secret-key-for-testing
AES_KEY=<运行下方命令获取>
CORS_ORIGINS=http://localhost:5173,http://127.0.0.1:5173
DEBUG=true
```

生成 AES_KEY：

```powershell
python -c "from cryptography.fernet import Fernet; print(Fernet.generate_key().decode())"
```

初始化种子数据：

```powershell
python scripts\seed_data.py
```

启动后端：

```powershell
uvicorn main:app --reload --port 8000
```

验证：浏览器访问 http://127.0.0.1:8000/docs 应看到 Swagger 文档。

### 2.4 前端

新开 PowerShell 终端：

```powershell
cd c:\vscode\wizzy\web
npm install
npm run dev
```

访问 http://localhost:5173

## 4. API 测试（Swagger）

访问 http://127.0.0.1:8000/docs：

1. POST `/api/auth/login` 获取 token
2. 点击 Authorize，输入 `Bearer <token>`
3. 依次测试各模块 CRUD 接口

## 5. 数据隔离验证

1. admin 登录，记录备忘录数量 N1
2. 退出，user 登录，记录数量 N2
3. 确认 N1 ≠ N2（各自独立数据）
4. user 无法通过 API 访问 admin 的数据（返回 404）

## 6. 故障排查

```powershell
# 检查 MySQL 服务
Get-Service MySQL*

# 检查后端端口
netstat -ano | findstr 8000

# 检查前端端口
netstat -ano | findstr 5173

# 后端日志直接输出在 uvicorn 终端

# 重新初始化数据（会跳过已有数据）
python scripts\seed_data.py
```

如需完全重建数据库：

```powershell
mysql -u root -p -e "DROP DATABASE IF EXISTS wizzy_db;"
mysql -u root -p < server\scripts\init_db.sql
python scripts\seed_data.py
```
