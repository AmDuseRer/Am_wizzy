# 后端技术架构

## 1. 总体架构

小智工具箱后端采用 **FastAPI 异步框架 + SQLAlchemy ORM + MySQL 5.7** 的经典三层架构：

```
┌─────────────────────────────────────────┐
│           API 路由层 (app/api/)          │
│   auth / users / memos / passwords ...  │
├─────────────────────────────────────────┤
│         业务服务层 (app/services/)       │
│   鉴权、CRUD、加密、日志、PDF 生成       │
├─────────────────────────────────────────┤
│          数据访问层 (app/models/)        │
│   SQLAlchemy Async ORM + MySQL InnoDB   │
└─────────────────────────────────────────┘
```

## 2. 核心模块

### 2.1 配置模块 (core/config.py)

- 基于 `pydantic-settings` 从 `.env` 加载配置
- 关键配置项：`DATABASE_URL`、`JWT_SECRET`、`AES_KEY`、`CORS_ORIGINS`

### 2.2 安全模块 (core/security.py)

| 功能 | 实现 |
|------|------|
| 密码哈希 | passlib + bcrypt |
| JWT 签发/解析 | python-jose |
| AES 加解密 | cryptography.Fernet |
| 密码脱敏 | 保留首尾字符，中间 **** |

### 2.3 依赖注入 (core/deps.py)

- `get_current_user`：解析 JWT → 校验 Token 表 → 返回 User
- `require_admin`：校验 role == admin
- `get_client_ip`：获取客户端 IP 用于日志

### 2.4 异常处理 (core/exceptions.py)

统一响应格式：

```json
{ "code": 0, "message": "success", "data": {} }
```

- `code=0` 表示成功
- `BusinessException` 携带业务错误码
- 全局 Exception 处理器捕获未预期错误

## 3. 鉴权架构

```
登录 → Bcrypt 验证 → 签发 JWT(含 jti) → 写入 user_tokens 表
请求 → 解析 JWT → 查 user_tokens(jti, is_revoked) → 放行/拒绝
登出 → revoke 当前 jti
改密 → revoke 该用户全部 jti
```

JWT Payload 结构：

```json
{
  "sub": "用户ID",
  "username": "用户名",
  "role": "admin|user",
  "jti": "唯一令牌ID",
  "exp": "过期时间戳"
}
```

## 4. 数据隔离

所有业务表（memos、password_entries、todos、categories）均含 `user_id` 外键。Service 层强制过滤：

```python
query.where(Model.user_id == current_user.id)
```

admin 用户管理模块不受此限制。

## 5. 加密策略

| 数据类型 | 加密方式 | 存储位置 |
|----------|----------|----------|
| 用户登录密码 | Bcrypt 哈希 | users.password_hash |
| 密码本敏感字段 | Fernet AES | password_entries.password_enc |

密码本列表接口仅返回脱敏字段；查看明文需 POST 登录密码二次校验。

## 6. 日志体系

- **应用日志**：Python logging，stdout 输出
- **操作日志**：operation_logs 表，记录高危操作（删除密码、导出备份、禁用用户等）

## 7. 技术选型

| 组件 | 版本/库 | 用途 |
|------|---------|------|
| Web 框架 | FastAPI 0.115 | 异步 REST API |
| ORM | SQLAlchemy 2.x async | 数据库操作 |
| 数据库驱动 | aiomysql | MySQL 异步连接 |
| 校验 | Pydantic v2 | 请求/响应模型 |
| PDF | fpdf2 | 备忘录 PDF 导出 |
| 服务器 | Uvicorn | ASGI 运行 |
